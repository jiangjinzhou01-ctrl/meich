## 浏览器覆盖

主巡检覆盖 320 / 360 / 390 / 412 / 430 / 768 / 1024 / 1440 / 1920px，18 个核心路由，共 162 组。逐组检查整页宽度、单一 h1、文档语言、首屏图片、canonical 和 description。

路由包括：中英文首页；三个中文旗舰案例及对应英文页面；中英文服务、Culture × AI、研发、联系；案例与产品目录。英文里耶和雪城继续使用既有 brochure 路径。动效脚本还保留历史 375px，覆盖十个宽度、公共页面和更多英文入口。

真实操作检查包括：

- Hero CTA 立即可见；手机、平板、大屏及窄横屏构图；禁用 JavaScript 后标题、摄影和案例入口仍可用。
- 菜单多次打开、动画中途退出、焦点隔离、Esc、滚动锁恢复、主题持久化及语言切换。
- Culture 四阶段、三视角、快速反向切换、Home/End/方向键、原图弹层、原始尺寸、焦点返回；320/390/768/1440px 的中英文阶段高度稳定。
- 三旗舰在 360/430/1440px 的中英文章节前进、回退、快速反向选择；真实取景控件、完整档案展开、能力/合作链接及下一项目路径；刷新后深层页面可读。
- 搜索结果、无结果与重置；产品筛选 URL 与刷新恢复。
- 中英文表单五项校验、错误汇总焦点、本地整理的明确未发送状态、实际剪贴板内容、实际下载文本、剪贴板失败降级、已知项目上下文。

- 品牌影片仅在用户打开后创建 video，controls=true、autoplay=false，退出后卸载。验收拦截了外部大影片传输，未声称完整播放通过。

宽度巡检不等于 162 张人工视觉审阅。实际人工复核了 320/390/768/1440/1920px 首页、三个案例的桌面资料区、里耶手机阅读区与 Culture 桌面/手机，发现平板入口裁切偏紧后已调整独立构图。

## 实际性能测量

Lighthouse 13.0.1，独立运行，本地 gzip 静态生产导出 `/meich`，每个 preset 一次冷导航。移动端 412×823、DPR 1.75，模拟 RTT 150ms / 1638.4Kbps / CPU 4×；桌面 1350×940、DPR 1，模拟 RTT 40ms / 10240Kbps / CPU 1×。这是 Linux 云容器中的实验室样本，不是 GitHub Pages 实际用户数据或真机结果。

| 最终记录 | 移动模拟 | 桌面模拟 |
| --- | --- | --- |
| Performance | 80 | 86 |
| FCP | 0.9s | 0.3s |
| LCP | **3.1s，未达到 2.5s 目标** | 0.8s |
| CLS | 0 | 0 |
| TBT | 520ms | 310ms |
| 本次测量总传输 | 约 554KB | 约 648KB |

**INP 未测量。TBT 不能代替真实 INP；没有声称完整 Core Web Vitals 达标。** 总传输是该次导航记录，包含脚本、样式、字体及浏览器触发的图片请求，不是单独的 Hero 文件。手机 Hero WebP 52,764 bytes。

真实初测移动 LCP 为 3.3s。检查后将 MotionProvider 几何读取与样式写入分批，保留原观察器。复测仍高于移动目标；关闭摄影入场的隔离实验也未形成有效改善，因此没有为分数牺牲首屏构图。未根据单样本差异声称提升百分比。后续需在目标 Android/iOS 和真实网络上确认加载/主线程成本，再评估更深的首屏资源与客户端拆分。

## 发现与修复

首轮导出发现五处英文链接使用了不存在的简写路径，已改用 `languagePair` 并复验归零。英文雪城原入口未进入旗舰组件，且英文第四章缺失，现已补齐既有中文内容的翻译。

实测发现 320px Culture 阶段高度变化、快速反向原生锚点仍停在先前目标。已按窄屏/语言预留真实最长阅读高度，并在新章节请求前取消上一次 smooth scroll。复测通过。

初轮失败文件保留为 `v3.0-browser-initial.json` 与 `v3.0-motion-initial.json`。其他测试问题包括未等 hydration 完成、资料嵌套节点选择过宽、横滑索引更新早于最终停稳、采样已关闭菜单的普通计算透明度；脚本已改为准确节点与实际状态条件，没有放宽产品结果。最后完整运行以非 initial 报告为准。

## 复跑与限制

```bash
npm ci
npm run typecheck
npm run check:search
NEXT_PUBLIC_BASE_PATH=/meich NEXT_PUBLIC_SITE_URL=https://jiangjinzhou01-ctrl.github.io/meich npm run build
npm run check:export
# 可选 QA 工具安装在仓库外，不改生产依赖：
npm install --prefix /tmp/mgc-qa --no-package-lock playwright@1.56.1
/tmp/mgc-qa/node_modules/.bin/playwright install chromium
MGC_PLAYWRIGHT_MODULE=/tmp/mgc-qa/node_modules/playwright npm run check:v3
npm run build:server
npm run package:server
MGC_PLAYWRIGHT_MODULE=/tmp/mgc-qa/node_modules/playwright MGC_QA_REPORT=v3.0-motion.json npm run check:motion
```

本环境使用 `MGC_CHROMIUM_PATH=/usr/bin/chromium` 与 `MGC_CHROMIUM_ARGS='["--no-sandbox"]'`。脚本不需要预先运行 next dev；`check:v3` 需要已生成 out，`check:motion` 需要已打包 standalone。构建必须顺序执行。

未完成实体 Android/iOS、Safari、真实软键盘、真实手指惯性、正式企业服务器部署、真实收件/接口失败与超时、完整外部影片播放。表单验收在未配置端点的本地模式，未向企业发送测试需求。素材像素、水印和公开职责边界见 [交付文档](V3.0-DELIVERY.md)。移动 LCP 和真实 INP 仍需后续验证与改善，不作为已达标项目。
