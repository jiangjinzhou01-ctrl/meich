2026-11-01 · Incremental upgrade from main `adef445`. Target branch: `feature/mgc-v3-experience`. Next.js 15 / React 19 / TypeScript, static GitHub Pages and standalone server retained. See [baseline decisions](V3.0-AUDIT.md) and [verification](V3.0-QA.md).

## Implemented experience

The home hero separates the actual Gaomiao exhibition photograph from the brand statement. The original light, earthen walls and entrance remain visible; only the small image caption uses a local gradient. Paper-white typography forms the transition into selected work. Desktop uses an editorial grid; mobile uses a dedicated, downsampled 640×800 crop retaining the sculpture and entrance. The CTA is available immediately. Photography has a slight entrance transform; there is no automatic video or continuous animation loop. HTML content and links remain usable without JavaScript, and reduced motion removes entrances.

Selected work remains immediately after the hero. Gaomiao is a spatial panorama, Liye uses a light editorial plate, and Potala uses a darker architectural composition. Project responsibilities remain visible. All three use existing project data, card semantics and route mapping.

Case pages add an actual scroll-driven chapter rail with current count, back/forward controls and mobile horizontal scrolling. A new selection cancels the previous smooth scroll; state is still determined by the page’s actual position. Native fragment links remain as the no-JS fallback. All-work, full archive and next-project paths stay intact.

ProjectStudy shares a component while giving the cases different media behavior: Gaomiao crops the real entrance photograph and adds four small interior records; Liye compares the existing three-layer interpretation plate, followed by its existing cinema reader in the spatial chapter; Potala switches between the architectural context and historical-life interior plate. No new transcription, scan, 3D model or project capability is claimed. A native image dialog exposes original pixels, fit/original-size controls, two-axis scrolling, Escape, scroll lock and return focus. The normal source link remains usable without JavaScript.

Culture × AI retains four stages and three reading lenses. Stage controls precede the material and remain available while reading. The standalone page replaces the duplicate large heading with concise guidance. Stage labels, source-image inspection, later-stage image explanations, related project chapters and research paths make the material easier to explore. Narrow bilingual reading areas reserve space for the longest actual state. It remains a curated concept with no live AI service.

Services now connect published responsibilities to real cases, with correct examples for digital exhibitions and digital museums. Cases link to their capability and an editable project-context brief. Contact validation, copy, download, error focus and local-only semantics remain. Formal telephone, address and original contact channels are unchanged. No endpoint means no submission or success claim.

English Snow City now uses the same flagship experience as Chinese. Its missing fourth English chapter is translated from the existing Chinese content. Original archives and old routes remain. Media navigation uses opaque ink for readable text, with stacking above chapter controls.

## Maintenance and release

`ResponsiveImage.mobileSource` is explicit art direction; do not restore the former implicit portrait rule for every `100vw` Gaomiao image. Update the corporate URL mapping when replacing a record, preserving the original source URL and caption. Keep English text in step with the actual Chinese chapter count. Case routes must use `languagePair`, including the existing English brochure slugs.

The public enquiry endpoint is injected at build time. Pages uses the existing `CONTACT_ENDPOINT` repository variable; standalone builds also need `NEXT_PUBLIC_CONTACT_ENDPOINT` at build time. A local prepared brief is not delivery. Do not test an unapproved external recipient with production personal data.

Build targets share `.next`: finish the `/meich` static build and export check before `build:server` and `package:server`. The optional browser tools are installed outside the repository; reproduction commands are in README and QA. PR CI retains screenshots/reports and both production targets; the existing main-only Pages workflow performs release. Do not force push or bypass failed checks.

Physical Android/iOS, Safari, real soft-keyboard behavior, real receiving infrastructure and complete external-film playback require company/device validation. Browser width/touch emulation does not establish those results. Performance lab measurements are recorded separately from functional builds; field INP is not inferred from them.
