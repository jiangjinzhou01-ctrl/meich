# 交互登记
| 入口 | 实际行为 |
| --- | --- |
| 正式 Logo | 返回当前语言首页 |
| 导航与语言 | 对应稳定路由，当前页标注 |
| 移动菜单 | 原生 dialog；关闭、Esc、焦点隔离与滚动恢复 |
| 主题 | localStorage 持久化；系统偏好作为初始值 |
| Hero CTA | 进入案例；Scroll 进入文化转化过程 |
| 影片 | 用户打开弹层后才加载；播放/关闭/原文件入口 |
| 服务索引 | 点击、触控、hover 与键盘切换；链接产品领域与相关案例 |
| 搜索 | 本地四类型索引；提交引导、URL、计数、分类、空态、重置、加载更多 |
| 产品筛选 | 真实原分类；旧标签与 domain URL 兼容 |
| 案例 | 章节、释读热点、完整原文与图集、下一个项目 |
| Culture × AI | 四阶段、方向键/Home/End、重置；预置概念 |
| Research Canvas | 原图片、采样、网格；按钮触发重绘，无持续 RAF |
| Evidence | 官方公开记录或专利文献新窗链接 |
| 联系 | 电话、地址复制、需求整理；接口未配置不显示送达成功 |
| 原有报名/体验 | 保留原站正式外链 |
| 页脚 | 合法页面、回顶、品牌工作台 |

链接用于导航，按钮用于状态与动作。没有 href="#"、空地址或假送达操作。原站外部系统的后台不包含在上传源码中。
