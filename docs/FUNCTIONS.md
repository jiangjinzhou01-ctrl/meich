## 服务边界

GitHub Pages提供静态托管；原站的登录、收件、伙伴申请、研发报名及后台数据处理仍在原服务器运行。现有接口没有跨域许可，因此未在GitHub Pages中伪造直接提交成功，而是进入原站正式表单处理。

视频文件、完整图集、附件、外部展厅与设计工具继续使用公开原地址；293张目录与封面图片已本地优化，主要首页和精选图片也在本地托管。

原后台发布的新内容，不会实时写入GitHub Pages。GitHub Actions支持手动选择 `refresh_content`，重新读取公开内容并部署。后台的访问统计仍对应原站；统一后台、实时发布及新版访问统计需要现有源码和服务器配置，尚未迁移至GitHub Pages。

## 更新内容

```bash
python -m pip install -r scripts/requirements.txt
python scripts/sync-source.py
npm run build
```

脚本只读取公开页面，不登录后台、不调用写入API。全部页面抓取成功后才更新快照；某个页面失败时保留当前快照，避免部署缺失内容。新封面未本地缓存时自动使用官网原图。
