# 美创数字官网改版

首页面向正在筹备博物馆、展馆和文旅项目的合作方。首页是一组可翻阅的展览图版。里耶封面的两枚简牍截自该馆真实释读图，另两版使用齐白石精品展与「听见湖湘」的展览现场摄影。三张图版均是本次网页新编的封面。访客可拖动、使用方向键，或直接打开选中的项目。里耶制作手记将简牍陈列调试照片与释读版面对照。中英文均可通过相同的导航找到业务、研究和公司资料。

| 内容 | 仓库依据 | 新版入口 |
| --- | --- | --- |
| 公司介绍、品牌沿革、公开联系渠道 | `lib/content.ts`、原站快照、`docs/SOURCES.md` | 关于美创、项目咨询 |
| 数字展示、数字文博、数字文创、数字运营 | `lib/content.ts`、快照中的四条业务与产品资料 | 业务与产品、场景方案、产品目录 |
| 里耶、雪城、高庙 | `lib/content.ts`、项目快照与 `public/brand/` 中对应图版 | 首页精选、统一案例库、三组项目详情 |
| 历史案例、新闻、影片和线上体验 | `lib/source-pages.json`、`lib/source-taxonomy.json`、`lib/source-image-map.json` | 各主题目录及既有详情地址 |
| 企业技术中心及其他公开记录 | `lib/evidence.ts`、`docs/EVIDENCE.md` | 研发与公开记录 |
| 研发方向、图像采样、Culture × AI | 研发快照与既有演示资产 | 研发、Culture × AI 的独立体验页 |

高庙宣传册载有 2024 年，精选项目数据未录入年份。项目页根据已核对的展陈与数字互动记录呈现，具体年份待企业确认。首次上线前由企业确认正式收件配置与现行资质口径。咨询表单按配置提交。预览的本地模式支持复制或下载需求，并显示正式联系渠道。

项目索引默认打开目录。在桌面移动指针或用键盘切换项目，即可在旁边看到现场摄影。目录和图像两种视图可切换，筛选条件和浏览方式均可通过网址恢复。研发扉页的象纹大铜铙图取自美创「云观博」影片第 64 秒。原始图片和影片出处见 [素材索引](source-assets.json)。

## 验收与预览

按 README 中的静态和服务器命令分别构建。浏览器回归覆盖九种屏宽、中英文对应路由、案例搜索与返回恢复、项目咨询带入、键盘导航、触摸滑动、品牌影片按需加载，以及服务器模式下的本地草稿。新版截图和检查报告输出到 `qa-results/redesign/`。团队可以用 `MGC_REDESIGN_QA_DIR` 指定输出目录。
