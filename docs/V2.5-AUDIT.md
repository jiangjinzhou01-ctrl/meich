## Findings and priority
| Priority | Finding / root cause | Decision |
| --- | --- | --- |
| P0 regression guard | No current submission endpoint is assumed. Existing no-endpoint branch correctly says not sent. | Keep truthful local preparation; add copy feedback, lock edits during submission, retain download on failure. Do not send external test data. |
| P1 | Selected work follows manifesto, reel and a five-step journey; proof is reached late. | Bring selected work immediately after Hero; combine the manifesto and film entry into one quiet editorial bridge. |
| P1 | Artifact stages 1/2 repeat images without distinguishing the absence of acquisition footage. Desktop IO updates depend on entry ordering. | Distinct editorial plates/crops and source captions, explicitly mark acquisition as documentation; select the nearest desktop chapter at a stable viewport anchor; retain the mobile rail. |
| P1 | Culture lab tabs change background and prose but decorative brackets do not help interpret the source. Generated imagery interrupts the real-material narrative. | Retain four tabs; add three reviewed reading lenses with synchronized image framing and explanatory text; use real interpretation/design/space records. No live AI claim. |
| P1 | Key Hero link has delayed entrance; all editorial headings use blur by default. | Keep CTA immediately visible, reserve scene motion for photography, remove default editorial blur and media zoom. |
| P1 | Full-width image `sizes` silently inflates mobile widths for every image. | Make cover sizing explicit; use actual layout sizes for other media and half-width project cards. |
| P2 | Same generic case chapter categories mislabel actual article content; interactive reading has no visible selection count. | Give case-specific chapter labels; add reading index and accessible relationship. Preserve published text. |
| P2 | Mobile/English line lengths, source labels, sticky/readout contrast require fresh validation. | Validate production output through an isolated static preview and width harness; document browser/physical-device limits. |
